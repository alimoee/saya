# علی۲ — بازاریاب خودکار سایا

## فایل‌ها
- `.github/workflows/ali2-daily.yml` — ساعت‌کار خودکار (۹ صبح)
- `scripts/ali2_run.py` — موتور ارسال و پیگیری
- `campaign.csv` — لیدها (شما پر می‌کنید)

## راه‌اندازی
1. بات تلگرام: @BotFather → /newbot
2. Chat ID: @userinfobot
3. رمز اپ جیمیل: myaccount.google.com/apppasswords
4. Secrets (Settings > Secrets > Actions):
   TG_TOKEN, TG_CHAT, SITE_URL, SMTP_HOST, SMTP_USER, SMTP_PASS
5. Actions > Ali2 Daily Marketing > Run workflow

## کار روزانه
گزارش صبح به تلگرام می‌آید + بسته واتس‌اپ با لینک یک‌کلیکی
